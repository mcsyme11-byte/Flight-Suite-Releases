The installer and manager for the Flight Deck Suite: checks the PC, installs, updates, starts and removes the apps.

**New in 0.1.5:**

- The Flight Deck Suite mission patch is the Manager's new logo: in the window, the taskbar, the notification area and the Start menu.
- Each app's card and row shows its own badge, the patch's frame with the app's symbol.
- Running the setup file opens a setup window with the patch: it asks before installing and shows the install's progress.
- About shows the trademark line under the credit.

**Already have the Manager?** Open **Updates** and select **Update** next to Flight Deck Manager (not during a flight). New here? Run **FlightDeckManager-Setup.exe** and select **Install** in the setup window to install it for your Windows user (no administrator rights needed).
