The installer and manager for the Flight Deck Suite: checks the PC, installs, updates, starts and removes the apps.

**New in 0.1.4:**

- Each app's Details page names every folder on this PC, such as Your flights, Playback recordings, Video clips and Screenshots, with a note on what's in it.
- How much space each folder takes, shown beside its name.
- Folder paths wrap neatly between folder names, and the Open buttons line up.
- Settings › Folders also lists the Manager's own folder, with a note on each.
- Tidier layouts: every update shows its version and date, and badges and buttons sit evenly in a narrow window.

**Already have the Manager?** Open **Updates** and select **Update** next to Flight Deck Manager (not during a flight). New here? Run **FlightDeckManager-Setup.exe** and select **Yes** to install it for your Windows user (no administrator rights needed).
