Parks airliners on empty stands in the right airlines for each airport.

**New in 0.3.3:** Parked aircraft no longer vanish as you taxi past them; only the gate you park on or really pull into is cleared, and the aircraft beside your gate stay unless your wings would reach them.

**Most pilots don't need this file directly:** download Flight Deck Manager from the website, and it installs and updates this app for you. If Ramp is already installed through the Manager, select **Update** on Ramp's card.
