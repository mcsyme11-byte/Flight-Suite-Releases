The installer and manager for the Flight Deck Suite: checks the PC, installs, updates, starts and removes the apps.

**New in 0.1.3:**

- **Update alerts** (optional; the Manager asks once): it starts with Windows, waits beside the clock and shows a notification when an update is ready, never while MSFS is running. Switch it on or off in Settings.
- **Every update lists all of its changes**, and each app's Details page has its version history. Every version is also on the website's [What's new](https://mcsyme11-byte.github.io/Flight-Suite-Releases/whats-new.html) page.
- **Update all**, when more than one update is ready.
- **Repair** on an app's Details page installs the same version afresh. Your settings and data stay as they are.
- The app cards come first, and **Finish setting up** folds away once everything is set up. **Start with MSFS** moved to Settings; each app's card says when it opens with the sim.
- A **Help** page, and the Terms of Use, Privacy Policy and third-party notices on the About page.
- Each app's Details shows its real folders with **Open** buttons, and the copy kept by Take over can be deleted. Logbook's Details points to **Move to a new PC**.

**Already have the Manager?** Open **Updates** and select **Update** next to Flight Deck Manager (not during a flight). New here? Run **FlightDeckManager-Setup.exe** and select **Yes** to install it for your Windows user (no administrator rights needed).
