If something's not working

The problems pilots meet most often, each with its fix. Still stuck? The last section shows how to send the details in one click.

Installing

"Windows protected your PC"

Windows shows this for a new program it hasn't seen many times yet. Flight Deck Manager is new, so the warning appears at first.

  1. Select More info, check that it names FlightDeckManager-Setup.exe, then select Run anyway.
  2. Download it only from this website or its GitHub page, never from a copy someone sent you.
Flight Deck Manager

An install or update says it's waiting

That's on purpose. Nothing is installed, updated or removed while Microsoft Flight Simulator is running, so nothing changes in the middle of a flight. Squawk also waits for vPilot to close, because vPilot holds its files.

  1. Close the sim (and vPilot, for Squawk). The waiting install runs by itself within a few seconds; the Manager only has to stay open.
Flight Deck Manager

An app shows "Installed without the Manager"

The app was installed before the Manager, from a manual download. The Manager leaves it exactly as it is, so nothing of yours is replaced. It keeps working as before; it just isn't updated by the Manager.

Flight Deck Manager

Something you have shows "Not found"

  1. Microsoft Flight Simulator 2024: start the sim once and let it reach its main menu, so it creates its own folders, then select Look again in the Manager's Settings.
  2. FSLTL Base Models: they must be in the Community folder the sim uses. Install them with FSLTL's own installer (Before you start, step 5), then Look again.
  3. Anything else: a program installed somewhere other than its usual folder can't be seen. Reinstall it with its installer's suggested folder.
The Manager never downloads Microsoft Flight Simulator, vPilot, FSLTL or GSX. A program you already have is never downloaded again.
Flight Deck Manager

"Install for me" didn't work

For OBS Studio, Tailscale and Microsoft Edge WebView2, the Manager uses Windows' own installer, winget, to fetch the program from its official source.

  1. If Windows asked for permission, the install needs a yes. Select Install for me again and choose Yes.
  2. If the button isn't there, this copy of Windows doesn't have winget. Use Get it › instead: it opens the program's own page and the steps in Before you start.
Ramp, Vantage, the Manager

A window opens empty, or opens in the browser

These windows are drawn by Microsoft Edge WebView2, which is part of Windows 10 and 11 but can be missing.

  1. Install WebView2: the Manager's Install for me, or Before you start, step 6. Then start the app again.
Squawk

The phone can't open Squawk

  1. Start vPilot. Squawk runs inside vPilot, so its page is only there while vPilot is open.
  2. Check Tailscale on both devices: the same account on the PC and the phone, and both showing Connected.
  3. Use the PC's name in Tailscale: the address is http:// followed by the name Tailscale shows for the PC, then :8765. The Manager's Finish setting up card shows it, with a Copy button.
  4. Installed Squawk while vPilot was open? The Manager waits for it to close. Close vPilot, let the install finish, then start vPilot again.
Logbook

Logbook doesn't open with the sim

  1. Turn on Start with MSFS on the Manager's Apps page, with the sim closed. The Manager asks first and keeps a backup of the sim's start list.
  2. Or start Logbook yourself from the Start menu, before or during a flight. It notices the sim by itself.
Playback

Landing replays work, but no video clip is made

Replays and screenshots work without OBS Studio; only the video clips need it.

  1. Have OBS open when you play back the landing.
  2. Switch on OBS's remote control: in Logbook's Settings, select Set up OBS for me. Or by hand in OBS: Tools › WebSocket Server Settings › tick Enable WebSocket server › OK (Before you start, step 7).
Ramp

The gates stay empty

  1. Wait for the flight to load. Ramp fills the stands once your aircraft is on the ground and the flight is running, not on the loading screen.
  2. Check FSLTL Base Models in the Manager (Settings › This PC). Ramp parks FSLTL's aircraft, so it needs them.
  3. Look at Ramp's window: it says what it's doing at the airport, and why if it can't fill it.
Still stuck

Send the details

  1. In Flight Deck Manager, open Settings and select Copy details for support. It copies what the Manager sees on this PC, the apps' versions and the latest lines of its log. Your Windows user name and your PC's name are left out.
  2. Email mcsyme11@gmail.com, paste the details, and say what you were doing when it went wrong.
